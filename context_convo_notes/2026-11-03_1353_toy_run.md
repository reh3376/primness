# Toy Scale-Down Run (2026-11-03)

## Purpose
Verify the comparison structure (observed B-smooth density versus a Dickman-style prediction) before the full protocol is implemented. This is **not** the real D1 measurement on 40–80 digit instances.

## Run
- 10 small integer values
- Smoothness bound B = 10
- Crude Dickman approximation

## Results
- Observed B-smooth density: 0.000
- Dickman-style predicted: 1.000
- Gap: -1.000

## Analysis
The toy numbers and the extremely rough smoothness test produced a null observed density. The gap is large and negative, which under the stated rejection criterion would reject the claim on these toy instances. This is expected: the instances are not polynomial values from an optimized NFS polynomial, the sieve region is absent, and the Dickman approximation is crude.

## Implication for the real protocol
The structure (count observed density, compare to Dickman adjusted only by measured properties, apply 2σ rejection) is in place. The next real run requires:
1. Genuine 40–80 digit hard semiprimes
2. Polynomials from external instruments
3. Proper evaluation over a sieve region
4. Accurate smoothness testing and a better Dickman implementation

No tool heuristic was used. The result does not weaken or strengthen Obstacle D; it only confirms the measurement skeleton.
